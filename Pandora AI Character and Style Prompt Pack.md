# Pandora AI Character and Style Prompt Pack

## Use This Pack in Order

Create the **style-frame** first. Then create the Commander-in-Chief reference sheet and the spectral mentor reference sheet. Approve one preferred version of each before generating video. If Pandora AI supports reference-image conditioning, attach the approved relevant character image to every shot containing that character.

The wording in the **Global Style Lock** and each character’s **Identity Anchor** should remain unchanged across prompts. This repetition is more important than adding new adjectives in each shot.

> **Parody framing:** Every prompt in this pack is for a fictional, non-photorealistic adult-cartoon parody. Do not ask Pandora AI for fake news footage, realistic impersonation, a real endorsement, or fabricated factual events.

## Quality-Control Checklist

Before approving any generated image or clip, confirm the following requirements only.

| Check | Approval question |
| --- | --- |
| Character silhouette | Is the hair, costume, body shape, and facial structure consistent with the approved sheet? |
| Costume | Is the suit consistently navy, the tie-cape red, and the CIC emblem small and on the left breast? |
| Visual category | Does it read as an original 2D adult cartoon rather than a realistic impersonation or news clip? |
| Motion | Is there one understandable action, with no extra limbs or facial distortion? |
| Edit point | Does the clip begin and end on a held pose suitable for a cut? |
| Brand safety | Are there no readable claims, fake headlines, endorsements, real logos, or watermarks? |

## Prompt Troubleshooting

| Symptom | Prompt correction |
| --- | --- |
| The character’s hair changes shape | Repeat “preserve the approved reference image’s exact oversized swept blond hair silhouette” in the first and continuity paragraphs. |
| The face becomes too realistic | Add “flat 2D caricature, no skin texture, no pores, no photorealism” to the first sentence. |
| A shot contains too much action | Replace the action with one verb: “turns,” “raises eyebrow,” “materializes,” or “walks.” |
| Costume colors drift | Repeat exact palette names and attach the reference sheet. |
| Dialogue looks unusable | Ask for a closed-mouth reaction or an over-the-shoulder shot; record and sync dialogue in an editor instead. |
| AI inserts text or logos | Add “no readable text, no logos, no campaign branding, no interface labels” before the style lock. |
